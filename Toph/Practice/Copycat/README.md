# [Copycat](https://toph.co/p/copycat)

**Time Limit**: `1s` | **Memory Limit**: `512 MB`

## Problem Statement
Read an integer variable and print it.

Input

The input will contain an integer A (-200000000 < A < 200000000).

Output

Print the integer.

Example

Input

```
2
```

Output

```
2
```

**Sample Output:**
