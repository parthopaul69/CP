# [Pabak and Emon's MEX...](https://toph.co/p/pabak-and-emon-s-mex-challenge)

**Time Limit**: `1s` | **Memory Limit**: `512 MB`

## Problem Statement
Pabak and Emon were playing with an array. Emon gave Pabak an array of Nintegers and asked him a simple question.

**What is the MEX of the whole array?**

The **MEX** of an array is the smallest non-negative integer that does not appear in the array.

For example, the MEX of [0, 1, 3, 2] is 4, while the MEX of [1, 2, 3] is 0.

Help Pabak find the MEX of the given array.

Input

The first line contains an integer N (1 ≤ N ≤ 2 × 10³).

The second line contains N``integers A₁, A₂, ..., Aₙ (0 ≤ Aᵢ ≤ 10⁴).

Output

Print the MEX of the array.

Example

Input

```
5
0 1 2 4 5
```

Output

```
3
```
