You are given integers  A, B, C . If  A ≠ B  and  B = C , output `Yes`; otherwise, output `No`.

### Constraints

- 1 ≤ A, B, C ≤ 9

- All input values are integers.

## Input

The input is given from Standard Input in the following format:

```
A B C
```

## Output

Output `Yes` or `No` according to the instructions in the problem statement.

## Examples

**Sample Input 1:**

```
4 5 5
```

**Sample Output 1:**

```
Yes
```

**Sample Input 2:**

```
1 3 7
```

**Sample Output 2:**

```
No
```

**Sample Input 3:**

```
6 6 6
```

**Sample Output 3:**

```
No
```
